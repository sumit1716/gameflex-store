# 🎮 GameFlex Store - Digital Gaming Marketplace

A high-performance, mobile-responsive web platform designed for digital video game distribution. Features an immersive dark gaming aesthetic, real-time live search indexing, interactive cart architecture, and responsive layouts tailored for both desktop and mobile users.

## 🚀 Key Features

* **Real-time Predictive Search:** Instant client-side fuzzy searching with auto-complete dropdown for rapid game discovery.
* **Dynamic Cart Architecture:** Smooth slide-out cart drawer with real-time price calculation, item removal, and localized currency formatting.
* **Dual-Theme Design System:** Distinct thematic styles for PC (Red/Neon) and PlayStation 5 (PlayStation Blue/Glow) product lines.
* **Fully Responsive UI:** Engineered with mobile-first CSS media queries, featuring horizontal swipeable touch carousels and adaptive grid layouts.
* **Modular Codebase:** Structured for seamless integration with upcoming backend APIs (FastAPI/PostgreSQL) and payment gateways.

## 🛠️ Tech Stack

* **Frontend:** HTML5, Modern CSS3 (Grid, Flexbox, Custom Variables), Vanilla JavaScript (ES6+)
* **Icons & Typography:** FontAwesome 6, Google Fonts (Montserrat)
* **Architecture:** Component-driven static frontend with decoupled state management for shopping cart operations.
